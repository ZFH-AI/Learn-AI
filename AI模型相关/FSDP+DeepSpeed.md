# 1、Pytorch FULLY SHARDED DATA PARALLEL (FSDP)
是什么：FSDP是一种分布式训练策略，将模型参数、梯度、优化器状态切分（分片）到多个GPU上，实现显存高效利用。从而大幅降低每个 GPU 的显存占用，使原本单卡无法容纳的模型可以训练。

背景：传统DDP每个GPU有完整副本，显存冗余大，限制大模型训练。而 FSDP 则让每个 GPU 只持有一小部分参数，需要计算时再临时“拼凑”出完整参数，计算完立刻释放

核心原理：

1. 参数分片与按需重组（前向传播）
- 模型参数在初始化时被均匀分片到所有 GPU 上，每个 GPU 只保存属于自己的 参数分片。

- 当计算到某一层时，FSDP 会通过 all-gather 通信操作，从所有 GPU 收集该层的完整参数，在本地组装出一个临时完整副本。

- 完成该层的前向计算后，立即释放 不属于本 GPU 的参数部分，仅保留自己的分片。这样，前向传播过程中显存峰值只需容纳一层的完整参数，而非整个模型。

2. 梯度分片与聚合（反向传播）
- 反向传播时，再次通过 all-gather 收集该层的完整参数，计算出完整梯度。

- 紧接着执行 reduce-scatter 操作：对梯度在所有 GPU 间进行一次规约并散射，最终每个 GPU 只保留自己原来参数分片所对应的那部分 平均梯度，其余部分随即丢弃。

- 因此，每个 GPU 上只需存储与自己分片对应的少量梯度，而不是整个模型的梯度。

3. 优化器状态分片
- 由于每个 GPU 只需更新自己持有的那部分参数，其对应的 优化器状态（如 Adam 的动量、方差）也只维护这一部分，同样被分片存储。

- 参数更新完全在本地执行，无需额外通信。

4. 计算与通信重叠
- FSDP 会预先 预取（prefetch） 下一个将要计算的层的参数：在当前层还在计算时，后台就开始为下一层发起 all-gather 通信。这样通信时间可以被计算时间隐藏，提升整体吞吐。

简而言之，FSDP 通过 “按需收集、用完即丢、各自更新” 的方式，将原本需要整卡备份的大模型切割到多卡上，实现了类似 DeepSpeed ZeRO Stage 3 的效果，让训练超大规模的模型成为可能，同时保持了较好的扩展效率


# 2、DeepSpeed ZeRO Stage 3

DeepSpeed ZeRO Stage 3，与 PyTorch FSDP 理念一脉相承，都是为了在多 GPU 上训练超大模型而将内存冗余降到极致的策略。它分别对优化器状态、梯度和模型参数进行分片，Stage 3 是其中最彻底的级别：三者全部分片，几乎消除了所有冗余存储。

核心原理如下：

1. 分片存储，无整卡副本
模型初始化时，参数被均匀切分到所有 GPU 上。每个 GPU 只永久保存自己的那部分：

- 参数分片（parameters）

- 对应的梯度分片（gradients）

- 对应的优化器状态分片（如 Adam 的一阶、二阶动量）

这与传统数据并行在每个 GPU 上保留完整模型形成鲜明对比，显存占用从整块降到约 1/GPU 数量。

2. 按需收集参数（前向与反向）
当计算需要某一层的完整参数时：

执行 all-gather 通信，从所有 GPU 上收集该层的参数碎片，在本地拼出一个临时的完整层参数。

计算该层的前向或反向，随后立即释放非本地的参数部分，仅保留自己的分片。

这样做显存峰值只有单层参数的大小，而非整个模型。

3. 梯度分片与聚合（反向传播）
反向计算出完整梯度后，不再保留整个梯度张量：

执行 reduce-scatter 操作，对所有 GPU 上的梯度进行规约（求和／平均），并按照参数分片方式直接散射回去。

每个 GPU 最终只得到与自己参数分片对应的那部分规约后的梯度，其余梯度丢弃。

这样，梯度也被分片保存，没有冗余。

4. 本地更新与状态分片
因为每个 GPU 只负责更新自己的参数分片，它只需维护这些参数对应的优化器状态。

利用本地保持的梯度分片，直接在本地执行 optimizer.step()，无需额外通信。

优化器状态同样被切分，每个 GPU 只存一小部分，完全消除了冗余。

5. 通信与计算的重叠
ZeRO Stage 3 会采用参数预取和梯度推迟等技术：在当前层计算的同时，后台通信（all-gather 下一层参数或 reduce-scatter 上一层梯度），将通信延迟隐藏，保持计算单元忙碌。

简而言之
“需要时 gather，用完即丢弃，各管各的更新”。ZeRO Stage 3 将巨大的模型内存需求（参数、梯度、优化器）分割到所有 GPU 上，让单卡显存不再成为训练万亿参数模型的瓶颈，同时理论计算效率与普通数据并行相当（仅增加必要的通信）。这就是它与 PyTorch FSDP 共同遵循的核心理念，也是目前分布式训练巨模型的最常用方法之一。
