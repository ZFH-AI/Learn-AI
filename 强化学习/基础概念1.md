# 3.Reward and Return
## 3.1.Return 
定义：return -> cumulative future reward 未来的累计奖励
- Ut = Rt + Rt+1 + Rt+2 + ...
- 未来的奖励没有现在的奖励有价值；Future reward is less valuable than present reward
- Rt+1 的权重应该小于 Rt；Rt+1 should be given less weight than Rt
定义：discounted return -> cumulative discount Future reward 未来累计的折扣奖励
- γ 折扣率 超参数
- Ut = Rt + γRt+1 + γ^2Rt+2 + γ^3Rt+3 + ...
