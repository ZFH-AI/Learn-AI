# lesson 1 
强化学习：智能体通过与环境交互试错，学习从状态到动作的最优策略，以最大化长期累积奖励
- 终极目标：学习从状态到动作的最优策略
- 优化目标：以最大化长期累积奖励
- 强化方式：智能体通过与环境动态交互试错

终极目标：最优策略
- 什么是策略

   1、从状态输入到动作输出的函数映射，既告诉我们在任何一个状态应该采取什么行动

     状态 s ——————> 策略 π ——————> 动作 a

奖励（reward）：标量，可正可负
- 在每一个状态、采取一个动作都会得到一个奖励
- 奖励由人设定，从而实现想要的策略-人机交互的方法，简单而又繁琐

回报（return）：沿着一条轨迹得到的奖励总和

  return = R_1 + γ * R_2 + γ^2 * R_3 + ....


状态值（State Value，V_π(s)） 按照给定策略从状态 s 出发得到的回报的平均值，衡量策略的好坏，策略评价

最优策略：相比其他所有策略，最优策略的状态值或者状态值的平均值最大

强化：
- 如果采取一个动作得到了正的奖励，则下次会增大选择该动作的概率
- 如果采取一个动作得到了负的奖励，则下次会减小选择该动作的概率
