# 1、车联网
广义车联网包括车内网，车际网和车云网；狭义车联网专指车际网V2X，即车路云一体化协同
- 车内网：包括通过控制器局域网（CAN）或车载以太网实现汽车内部控制系统与各检测和执行部件间的数据通信
- 车云网：指车辆通过3G/4G网络实现与互联网的无线链接，如地图下载、远程诊断、车辆调度等
- 车际网：通过高可靠低时延的4G/5G无线通信技术，实现车-车、车-路、车-人之间信息互通，包括C-V2X和DSRC技术

V2V：通过车载终端进行车辆之间通信
V2N：车载终端通过无线网络与云平台通信
V2I：车载终端与路测设施通信
V2P：车与人的用户设备进行通信

```shell

    聪明的车                           |   智慧的路                                    |  可靠的网               |     强大的云

     |- V2V -- car ------------V2N UU口下发----------------> 5G基站--------------------------->| 通信网络  | ------------>  V2X业务平台、交通服务、地图服务 
     |          |                              |               |                              |          |
car -|- V2I -----------------------------> 路侧 RSU---------->MEC 路侧融合感知引擎------------->|          |
     |          |                              |               |
     |- V2P -- Person                         信号灯            路侧感知设备(摄像头、雷达)

```

# 2、车联网目标及应用场景
- 聚焦实现三大目标

   1、 提升驾驶安全：实时车车、车路、车云信息交互预警提醒，降低人为因素导致的安全事故：超视距、实时红绿灯、路况、限速等

   2、加速自动驾驶：降低单车智能成本及技术要求，使能高阶别自动驾驶：视觉盲区、博弈协同等

   3、提供交通效率：实时车路数据交互，拥堵提醒，诱导预警等错开高峰拥堵路段，提升交通通行效率：红绿灯调优，拥堵提醒，智慧公交等

- 车路协同主要应用场景

   1、城市道路：超视距路况感知、营运车辆违法治理、红绿灯信号调优、红绿灯提醒

   2、高速公路：二次事故预防、高速匝道并线事故预防、融合指挥、流量监控

   3、C-AD协同式自动驾驶：一键召车、自动停车，港口自动驾驶物流车、矿山运煤干线无人编队驾驶、无人清洁车、无人快递侧

# 3、车联网的发展

| \  | 车载信息服务阶段（2012-2020）| 智能网联汽车阶段（2020-2025）| 智慧出行阶段（2025 -- ）|
|:-- |:-- |:-- |:-- |
| 阶段特征 | 提供车载娱乐等基础信息服务| 尝试初级网联功能，初步具备智能化、网联化 | 实现网联驾乘体验、统一管理检测调度 |
| 技术网联 | 2-3-4G + GPS | 4-5G + V2X终端 + GPS | 5G/5G-A + V2X 终端 + GPS |
| 业务特点 | 人为主动驾驶（基础导航+媒体娱乐+救援呼叫）| 车路协同辅助驾驶（人车互联+初级自动驾驶+车路协同尝试）| 车路协同自动驾驶（高级无人驾驶+共享出行+协同式智能交通）|
