# 1、车联网
广义车联网包括车内网，车际网和车云网；狭义车联网专指车际网V2X，即车路云一体化协同
- 车内网：包括通过控制器局域网（CAN）或车载以太网实现汽车内部控制系统与各检测和执行部件间的数据通信
- 车云网：指车辆通过3G/4G网络实现与互联网的无线链接，如地图下载、远程诊断、车辆调度等
- 车际网：通过高可靠低时延的4G/5G无线通信技术，实现车-车、车-路、车-人之间信息互通，包括C-V2X和DSRC技术

V2V：通过车载终端进行车辆之间通信
V2N：车载终端通过无线网络与云平台通信
V2I：车载终端与路测设施通信
V2P：车与人的用户设备进行通信

```shell

    聪明的车                           |   智慧的路                                    |  可靠的网               |     强大的云

     |- V2V -- car ------------V2N UU口下发----------------> 5G基站--------------------------->| 通信网络  | ------------>  V2X业务平台、交通服务、地图服务 
     |          |                              |               |                              |          |
car -|- V2I -----------------------------> 路侧 RSU---------->MEC 路侧融合感知引擎------------->|          |
     |          |                              |               |
     |- V2P -- Person                         信号灯            路侧感知设备(摄像头、雷达)

```

# 2、车联网目标及应用场景
- 聚焦实现三大目标

   1、 提升驾驶安全：实时车车、车路、车云信息交互预警提醒，降低人为因素导致的安全事故：超视距、实时红绿灯、路况、限速等

   2、加速自动驾驶：降低单车智能成本及技术要求，使能高阶别自动驾驶：视觉盲区、博弈协同等

   3、提供交通效率：实时车路数据交互，拥堵提醒，诱导预警等错开高峰拥堵路段，提升交通通行效率：红绿灯调优，拥堵提醒，智慧公交等

- 车路协同主要应用场景

   1、城市道路：超视距路况感知、营运车辆违法治理、红绿灯信号调优、红绿灯提醒

   2、高速公路：二次事故预防、高速匝道并线事故预防、融合指挥、流量监控

   3、C-AD协同式自动驾驶：一键召车、自动停车，港口自动驾驶物流车、矿山运煤干线无人编队驾驶、无人清洁车、无人快递侧

## 华为车联网解决方案：云端分级部署，UPF下移极致低时延

``` shell
             |  事件管理 | 安全管理 | 连接管理 | 数据开放 | 地图管理

             +----------------------------------------------------------+

            +------------------+                    +----------------+

            +------------------+                    +----------------+
                    |                                       |
             +----------------------------------------------------------+
             | 区域 V2XServer
             |
             |  事件管理 | 安全管理 | 连接管理 
             |  事件转发 | 接入鉴权 | 车辆设备连接 
             +----------------------------------------------------------+

                           +----------------------+
                           | 5G基站 UU + V2X协议   |
                           +----------------------+

                  OBU + 车机 -------------- PC5 ------------ OBU + 车机



```

中心V2X Server
- 集团V2X Server负责多个地市的V2X Server间的互通。
- 中心V2X Server负责中低优先级信息下发。
- 地图管理、数据北向接口等非实时业务功能保留在中心V2X Serve。
- 对所连接区域云的数据进行抽取、汇聚、多维存储，提供深度分析处理与可视化服务。支撑全域智能网联汽车监管。

区域V2X Server
- 区域级V2X Server负责高优先级5G V2X Server消息下发，保证低时延。
- 为满足车联网传输时延要求（下行20ms@99%），推荐UPF和区域V2X Server就近部署。
- V2X 消息同时支持pc5（借助RSU设备）广播通信和uu（5G）单播。


洞察观点：

1、V2X Server分级部署，区域中心各有侧重，产品部件全自研，支持安全可信部署；

2、覆盖国标中全部306种V2X事件，中心云数据挖掘有待加深，AI大模型赋能，持续增强；

3、车辆设备连接管理（车载终端），需被动录入信息，车辆接入率低，大规应用，需考虑，车载终端首次联网主动注册录入车联信息功能

- 
看得清
- 全要素感知：受天气，光照，密度影响，白天，光照正常，低密度车辆全要素感知输出较为准确
