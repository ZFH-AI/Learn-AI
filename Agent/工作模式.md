# 1、ReAct

ReAct（Reasoning + Action）：是由Google Brain提出的将推理与行动相结合的革命性范式，核心思想是通过模仿人类：思考 --> 行动 --> 观察 --> 在思考 闭环

## 1.1、ReAct工作模式
1. Tought 思考 ：给予当前和历史信息，LLM进行推理，分析现状，并决定下一步应该做什么
2. Action 行动 ：LLM决定调用那个工具，以及使用那个函数
3. Observation 观察：智能体执行行动（调用工具），并将返回的结果（如搜索结果、代码执行输出）作为观察
4. Loop 循环：智能体将观察到的新信息添加到历史中，然后回到第一步，基于新信息开始新一轮的思考，这个循环会一直运行，直到任务完成

```shell

           |  提交任务    |
           +-------------+
                 |
                 V

           +--------------------+         +----------+        +-------------+
                 |                           Action            Observation
               否|

             |  最终答案      |
```

# 2、Plan-And-Execute
“计划与执行"架构模式强调AI Agent在面对复杂任务时，能够进行系统性的规划和步骤分解，并按照计划逐步推进任务流程。该模式下AI Agent能够展现出类似人类的前瞻性和策略性思维
```shell

+-------------+      +--------------------------------+     +--------------------------------------+
| 用户请求      |---->| Planner 规划器                 |---->|   Plan 计划清单                       |
| 提出复杂任务  |     | 分析目标\拆解子任务\生成步骤清单  |     |  明确任务目标\拆分子任务\定义执行顺序   |
+--------------+     +--------------------------------+     |  指定工具/输入\设置验收条件            |
                              ^                             +--------------------------^-----------+
                              |                                |                       ^
+------------------+    +--------------------+    +------------V---------+    +------------------+
| Final Response   |<---| Executor 执行器    |     | Execution 执行进度   |    | Replanner         |
| 任务完成、输出结果 |    | 按计划逐步调用工具  |<--- | Step 1--N           |--->| 根据反馈调整计划   |
+------------------+    | 记录结果与状态      |     |                     |    | 处理异常与偏差     |
                        +--------------------+     +---------------------+    +------------------+

Palnner 先把复杂任务拆解 ----> Executor再按步骤逐项完成

1: Planning 规划阶段    2、Execution 执行阶段   3、Feedback 反馈阶段       4、Replan 可选重规划
- 理解任务目标            - 按步骤依次执行         - 检查结果是否满足预期     - 计划错误时局部修正
- 生成完整步骤            - 调用API等工具          - 发现错误或阻塞时上报     - 环境变化时动态调整
- 明确依赖关系            - 记录中间结果与状态      - 触发重试或重规划        - 继续执行剩余步骤
- 可先人工审核计划


核心组件
1、Planner 规划器               2、Executor 执行器                3、Replanner
 - 负责接受任务描述，将复杂         - 负责依序执行计划中的子任务       -在执行失败，信息变化或初始计划
   任务分解为结构化子任务，           并调用外部工具完成具体动作        不准确时，根据当前状态重新生成部分
   通常基于LLM生成步骤、工具          如查询、计算、写入、生成文件      或全部计划，提供容错能力
   输入参数与验收条件
```
